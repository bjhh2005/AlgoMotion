# 学习追踪高级分析演示案例

## 案例概述

此文档用于项目演示时说明默认学习进度数据的场景。
默认演示数据已写入 `data/learning-content/initial-progress.json`，用于当系统未读取到用户持久化学习进度时的前端默认展示。

演示学生：**李明**

目标：展示学习追踪高级分析模块如何从学习状态、知识传播、行为质量、投入成效和动机指数中识别学习问题，并给出可视化分析点。

## 2. 高级分析模块演示要点

### 2.1 学习热力图与状态分布

- `linear-list` 作为强项，显示为绿色高掌握节点。
- `stack` 和 `queue` 呈现黄绿色，代表“学习中”且有进步空间。
- `binary-search`、`binary-tree`、`graph` 等关键算法节点则为橙色/红色，提示重点干预。
- `ProgressDistributionChart` 能直观展示：已掌握 1/6、学习中 2/6、薄弱 3/6 的分布。

### 2.2 认知雷达图（Quality Depth）

- `linear-list` 的 `remember`、`understand`、`apply` 均较高，属于“基础认知稳固”节点。
- `binary-search` 在 `apply`、`analyze`、`create` 维度上明显不足，建立“记忆型应答但缺乏高阶思考”的图形。
- `stack` 的 `apply` 仍有提升空间，说明学生已经掌握概念，但对实际题目还不够熟练。

### 2.3 知识传播风险分析

- `binary-search` 是 `binary-tree` 和 `graph` 相关算法的前置依赖。
- `KnowledgePropagationGraph` 会标记它的传播强度为高，并将 `downstream_risk` 显示为 `high`。
- 这说明如果不先补强 `binary-search`，后续 `binary-tree`、`graph` 的理解会继续受阻。

### 2.4 行为分析与假努力识别

- `binary-search` 部分的低正确率与较高错误数，结合高尝试次数，可能被判定为“猜题/仓促答题”。
- `LearningBehaviorPanel` 可显示该节点的“rush_rate”、“guess_rate”上升，说明学生做题时存在急于求成。
- `stack` 和 `queue` 虽然学习时间较高，但正确率与置信度尚可，属于“有效投入”类型。

### 2.5 投入成效分析

- `graph` 的学习时长 35 分钟、正确率仅 0.38，提示投入与成效不匹配，属于“低效学习”节点。
- `stack` 的 65 分钟学习时长对应 0.72 掌握度，属于“高效型投入”节点。
- `EfficiencyGauge` 和 `InvestmentEffectivenessScatter` 会将 `graph` 标记为潜在的“假努力”或“方法问题”，给出优化建议。

### 2.6 动机指数展示

- 学生整体学习持续性较好（`linear-list` 8 天连续学习、`stack` 5 天），说明具备一定毅力。
- 但弱项节点连续学习天数短且复习提醒已到期，可能是“应试片段学习而非知识体系构建”。
- 动机指数可以展示：
  - 一致性得分：中等偏上
  - 毅力指数：稳定
  - 假努力怀疑：中等
  - 成长型思维得分：建议提升

## 3. 演示话术建议

1. “这是我们的默认演示学生数据，展示了一个从基础结构到算法难点的典型学习路径。”
2. “可以看到 `linear-list` 已经掌握，但 `binary-search`、`binary-tree` 和 `graph` 形成了一条薄弱链路，这是高级分析模块的核心发现点。”
3. “系统不仅看学习结果，还能分析行为质量：`binary-search` 这里表现为多次尝试、低正确率，说明学生不是没有做题，而是方法不对。”
4. “进一步结合投入成效，我们可以发现 `graph` 的学习时间相比收效低，提示教学干预应聚焦于概念理解和题解思路。”
5. “最后，动机指数和复习到期提醒帮助教师判断该学生是否需要更频繁的回顾安排，而不是简单依赖一次性刷题。”

## 4. 适配模块与演示页面

此案例可在以下模块中直接展示：

- `LearningAnalyticsPage` / `AdvancedAnalyticsDashboard`
- `KnowledgeHeatmap` 和 `ProgressDistributionChart`
- `CognitiveRadarChart`
- `KnowledgePropagationGraph`
- `InvestmentEffectivenessScatter`
- `LearningBehaviorPanel`

演示时建议先展示“基础视图”成绩分布，再切换到“高级分析”，让听众看到从单点进度到多维分析的闭环。

---

## 5. 结论

该默认数据案例展示了一个学生：
- 基础结构知识已经掌握；
- 中级线性结构学习中等偏上；
- 核心算法薄弱，尤其是与后续知识传播相关的 `binary-search` 和 `graph`；
- 行为分析提示存在“急于求成/猜题”风险；
- 投入成效分析显示需要优化学习方法，而非单纯增加时长。

这正是高级分析模块希望展示的价值：
> 从“哪些题做对”到“为什么会错”、“怎么优化学习路径”以及“哪些节点会拖累后续进度”。
