# A + B（两整数求和）

## 题目描述

给定两个整数 **x** 和 **y**（|x|, |y| ≤ 10^9，非高精度），计算并输出 **x + y**。

从标准输入读入两个整数，向标准输出打印它们的和。

## 示例

### 示例 1

**输入**

```
1 2
```

**输出**

```
3
```

**解释**：1 + 2 = 3

### 示例 2

**输入**

```
10 10
```

**输出**

```
20
```

**解释**：10 + 10 = 20

## 约束条件

- |x|, |y| ≤ 10^9
- 使用 C++ 提交
- 判题 `problem_id` 为 `1001`，时间限制 2s，内存限制 256MB

## 提示

- 使用 `std::cin` 读入两个 `int`，`std::cout` 输出它们的和。
- 注意输出格式需与期望输出一致（本题不要求额外换行）。
